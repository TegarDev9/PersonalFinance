Wallet

Accounts, transactions, holdings, summaries.

  • GET /api/wallet/summary
  • GET/POST /api/wallet/accounts
  • GET/POST /api/wallet/transactions
  • GET/POST /api/wallet/holdings

Budgets & Categories

Monthly budgets, inline edits, overspending alerts (n8n).

  • GET/POST/PATCH/DELETE /api/categories
  • GET/POST/PATCH/DELETE /api/budgets
  • GET /api/reports/budget
  • GET /api/budget/overspend

Automation & Exports

n8n webhooks, logs streaming, CSV/QIF/OFX exports, ZIP bulk.

  • POST /webhooks/n8n
  • GET /webhooks/n8n/logs(.jsonl|/stream)
  • GET /api/export/transactions.(csv|qif|ofx)
  • GET /api/export/bulk.zip

Getting Started

  1. Set environment variables (keys for providers, optional LOGS_AUTH_TOKEN).
  2. For persistence on Vercel, configure Vercel KV or Upstash Redis REST.
  3. Use Swagger/Redoc to explore endpoints and run requests.

Auth & Rate Limits

Logs endpoints can be protected by token via query (?token=), header (X-Logs-Token) atau Authorization: Bearer. Rate limit default 60 requests / 60s per IP untuk endpoint logs.

Persistence (Serverless)

File system pada Vercel bersifat read-only dan ephemeral. Aktifkan KV agar data persisten:

  • Vercel KV: set KV_REST_API_URL & KV_REST_API_TOKEN
  • Upstash Redis REST: set UPSTASH_REDIS_REST_URL & UPSTASH_REDIS_REST_TOKEN
